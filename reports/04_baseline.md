# Baseline: full-image classifier

Generated by `python -m mammalcam.models.baseline`. Do not edit by hand.

- Input: whole image resized to 224×224, no MegaDetector crop (51,129 images with exactly one of the classifier classes)
- Model: frozen `convnext_tiny.fb_in22k` embeddings + logistic regression (balanced class weights, C chosen by validation macro-F1)
- Same embeddings for every split strategy, so differences come from the split alone.
